# werewolf-helper
在[月下人狼](werewolf.com.cn)（werewolf.com.cn）房间页面添加一个可收起的侧边栏，用于记录和追踪玩家身份、占卜/灵能结果、处刑/袭击信息。

---

### 操作说明

#### 身份标记（左键 / 滚轮）

| 视角  | 操作  | 目标   | 行为             | 存储位置                       |
| --- | --- | ---- | -------------- | -------------------------- |
| 全局  | 左键  | 任意玩家 | 循环切换该玩家的身份职业   | `identity['global'][玩家ID]` |
| 全局  | 滚轮  | 任意玩家 | 快速循环切换该玩家的身份职业 | `identity['global'][玩家ID]` |
| 玩家  | 左键  | 任意玩家 | 循环切换该玩家的身份职业   | `identity[当前视角ID][玩家ID]`   |
| 玩家  | 滚轮  | 任意玩家 | 快速循环切换该玩家的身份职业 | `identity[当前视角ID][玩家ID]`   |

**职业循环顺序**：占卜师 → 灵能者 → 猎人 → 共有者 → ... → 村人 → null → 占卜师（双向循环）
配置读取房间配置，仅限普村。

---

#### 视角切换（右键）

| 视角 | 目标 | 行为 |
|------|------|------|
| 全局 | 任意玩家 | 进入该玩家视角 |
| 玩家 | 自己 | 返回全局视角 |
| 玩家 | 其他玩家 | 进入该玩家视角 |

---

#### 占卜/结果标记（滚轮 / 中键）

| 视角  | 操作  | 目标   | 行为                                        | 存储位置                   |
| --- | --- | ---- | ----------------------------------------- | ---------------------- |
| 玩家  | 滚轮  | 其他玩家 | 循环切换：`○` → `●` → `null` → `○`             | `action[当前视角ID][目标名]`  |
| 玩家  | 滚轮  | 自己   | 循环切换：`×（处刑）` → `×（袭击）` → `null` → `×（处刑）` | `action[当前视角ID]['自己']` |
| 玩家  | 中键  | 任意玩家 | 清空当前视角玩家对该玩家的行动记录                         | `action[当前视角ID][目标名]`  |

---

#### 清空操作（长按）

| 视角  | 操作          | 目标   | 行为                                    |
| --- | ----------- | ---- | ------------------------------------- |
| 全局  | 长按左键（500ms） | 任意玩家 | 清空该玩家身份（`identity['global'][玩家ID]`）   |
| 玩家  | 长按左键（500ms） | 任意玩家 | 清空 `identity[当前视角ID][玩家ID]`           |
| 玩家  | 长按右键（500ms） | 任意玩家 | 清空行动记录 + 清空身份`identity[当前视角ID][玩家ID]` |

---

### 侧栏显示

**全局视角**：
- 有身份 → 显示身份名
- 无身份 + 被标记过 → 显示 `○`（非灰区标记）
- 无身份 + 未被标记过 → 空白

**玩家视角**：
- 有身份 → 显示身份名
- 无身份 + 被当前视角标记过 → 显示对应符号（○/●）
- 无身份 + 未被当前视角标记过 → 空白

**左侧标记**：显示该玩家被当前视角标记的符号（○/●/×处刑/×袭击），或被全局标记的非灰区 `○`

**右侧显示**：身份名 或 标记符号

---

### 工具栏按钮

| 按钮 | 功能 |
|------|------|
| **读取** | 刷新玩家列表 |
| **导出** | 导出当前全局视角的完整操作链到剪贴板 |
| **重置** | 清空当前房间所有数据 |

---

### 导出格式

```
占卜师（2）
玩家A：玩家B●→玩家C○→玩家D●→玩家E○→×（袭击）
玩家F：玩家G○→×（处刑）

灵能者（1）
玩家H：玩家I○→玩家J●
```

---

### 数据存储

- 数据按房间号隔离存储
- 使用 `GM_setValue` / `GM_getValue` 持久化
- 不同房间的数据互不干扰
