# werewolf-helper

月下人狼（werewolf.com.cn）房间辅助脚本，在房间页面添加一个可收起的侧边栏，用于记录和追踪玩家身份、占卜/灵能结果、处刑/袭击信息。

[License: GPL v3](https://www.gnu.org/licenses/gpl-3.0)  
[GitHub](https://github.com/hebaiser/werewolf-helper)  
[GreasyFork 安装](https://greasyfork.org/zh-CN/scripts/592666)

---

## 安装

### 前置条件
需要安装用户脚本管理器：
- Tampermonkey (推荐)
- Greasemonkey (Firefox)
- Violentmonkey

### 安装步骤
1. 点击以下链接安装脚本：
   - [GreasyFork 安装](https://greasyfork.org/zh-CN/scripts/592666)
   - [GitHub 安装](https://github.com/hebaiser/werewolf-helper/raw/main/werewolf-helper.user.js)
2. 确认安装提示
3. 打开 月下人狼 房间页面
4. 侧边栏自动出现在页面左侧/右侧

### 快捷键
- Ctrl + Shift + S — 快速打开设置面板

---

## 功能特性

- 身份追踪 — 滚轮/右键菜单快速标记玩家职业
- 视角切换 — 右键切换不同玩家视角（视角操作模式独占）
- 占卜/灵能结果记录 — 滚轮/右键菜单标记 ○/● 结果
- 处刑/袭击记录 — 标记玩家死因
- 数据持久化 — 按房间号自动保存，刷新不丢失
- 导出功能 — 一键导出完整操作链，支持预览编辑
- 灰区计算 — 自动计算共灰区和独立灰区
- 发言高亮 — 点击玩家快速高亮其发言
- 自定义设置 — 主题、颜色、字号、位置全可调
- 两种操作模式 — 视角模式和菜单模式自由切换
- 可收起侧边栏 — 不干扰游戏

## 操作说明

### 两种操作模式

脚本提供两种操作模式，可在设置面板中切换：

| 模式 | 说明 |
|------|------|
| 快速模式 (默认) | 左键点击高亮发言，右键切换视角，滚轮快速标记身份和结果 |
| 菜单模式 | 左键点击高亮发言，右键弹出操作菜单 |

菜单模式更适合习惯图形化操作的玩家，所有操作通过右键菜单完成。

---

### 快速模式操作

#### 身份标记（左键 / 滚轮）

| 视角  | 操作  | 目标   | 行为           | 存储位置                     |
| --- | --- | ---- | ------------ | ------------------------ |
| 全局  | 左键  | 任意玩家 | 高亮该玩家发言 |  |
| 全局  | 滚轮  | 任意玩家 | 循环切换该玩家的身份职业 | identity['global'][玩家ID] |
| 玩家  | 左键  | 任意玩家 | 高亮该玩家发言 |    |
| 玩家  | 滚轮  | 任意玩家 | 循环切换该玩家的身份职业 | identity[当前视角ID][玩家ID]   |

职业循环顺序（自动读取房间配置）：
占卜师 → 灵能者 → 猎人 → … → 人狼 → 狂人 → 村人 → null → 占卜师

#### 视角切换（右键）

| 操作 | 目标 | 行为 |
|------|------|------|
| 右键点击 | 任意玩家 | 进入该玩家视角 |
| 右键点击 | 自己（玩家视角） | 返回全局视角 |
| 右键点击 | 其他玩家（玩家视角） | 切换至该玩家视角 |

#### 占卜/结果标记（滚轮 / 中键）

| 视角 | 操作 | 目标 | 行为 | 存储位置 |
|------|------|------|------|----------|
| 玩家 | 滚轮 | 其他玩家 | 循环切换：○ → ● → null → ○ | action[当前视角ID][目标名] |
| 玩家 | 滚轮 | 自己 | 循环切换：×（处刑）→ ×（袭击）→ null → ×（处刑） | action[当前视角ID]['自己'] |
| 玩家 | 中键 | 任意玩家 | 清空当前视角玩家对该玩家的行动记录 | action[当前视角ID][目标名] |

#### 清空操作（长按）

| 视角 | 操作 | 目标 | 行为 |
|------|------|------|------|
| 全局 | 长按左键（800ms） | 任意玩家 | 清空该玩家身份 |
| 玩家 | 长按左键（800ms） | 任意玩家 | 清空当前视角下该玩家身份 |
| 玩家 | 长按右键（800ms） | 任意玩家 | 清空行动记录 + 清空身份 |

---

### 菜单模式操作

| 操作     | 行为               |
| ------ | ---------------- |
| 左键点击玩家 | 高亮该玩家发言          |
| 右键点击玩家 | 弹出操作菜单，选择标记身份或结果 |

菜单内容：
- 无身份玩家：显示所有职业列表，点击标记
- 有身份玩家：显示该玩家视角的操作菜单
  - 自己：标记处刑/袭击/清除
  - 其他玩家：标记 ○/●/清除
  - 清除职业

---

## 侧栏显示说明

### 全局视角
- 有身份 → 显示身份名
- 无身份 + 被标记过 → 显示 ○（非灰区标记）
- 无身份 + 未被标记过 → 空白

### 玩家视角
- 有身份 → 显示身份名
- 无身份 + 被当前视角标记过 → 显示对应符号和序号（○/●）
- 无身份 + 未被当前视角标记过 → 空白

### 左侧标记
显示该玩家被当前视角标记的符号（○/●/×处刑/×袭击），或被全局标记的非灰区 ○

### 右侧显示
身份名 或 标记符号

## 工具栏按钮

| 按钮 | 功能 |
|------|------|
| 读取 | 刷新玩家列表和职业配置（房间人数变动时使用） |
| 导出 | 导出当前全局视角的完整操作链到剪贴板 |
| 重置 | 清空当前房间所有数据（不可恢复） |
| ⚙ | 打开设置面板 |
| < | 收起侧边栏 |

## 设置面板

点击工具栏的 ⚙ 按钮或按 Ctrl + Shift + S 打开设置面板。

### 通用设置
| 选项 | 说明 |
|------|------|
| 主题 | 浅色 / 深色 / 跟随系统 |
| 侧栏位置 | 左侧 / 右侧 |
| 宽度 | 小(140px) / 中(180px) / 大(220px) |
| 基础字号 | 8~20px 可调 |

### 操作模式
| 选项 | 说明 |
|------|------|
| 快速模式 | 右键切换视角，左键/滚轮快速操作 |
| 菜单模式 | 左键高亮发言，右键弹出操作菜单 |

### 死亡玩家
- 文字透明度：15%~75% 可调

### 职业颜色
- 预设方案：经典 / 柔和 / 高对比 / 色盲友好 / 自定义
- 自定义模式下可单独调整每个职业的颜色

### 导出预览
| 选项 | 说明 |
|------|------|
| 启用预览窗口 | 显示导出内容的实时预览窗口 |
| 显示共灰区 | 在导出中包含共灰区信息 |
| 显示独立灰区 | 在导出中包含每个占卜师的独立灰区 |
| 预览窗口大小 | 小 / 中 / 大 |
| 不透明度 | 30%~100% 可调 |

### 界面颜色
可自定义侧栏的所有颜色：
背景、主文字、次要文字、边框、分割线、高亮、悬停、标记符号、视角指示

## 导出格式示例

```
占卜师（2）
玩家A：玩家B●→玩家C○→玩家D●→玩家E○→×（袭击）
玩家F：玩家G○→×（处刑）

灰区：玩家H，玩家I，玩家J，玩家K

灵能者（1）
玩家L：玩家M○→玩家N●

人狼（2）
玩家O：×（袭击）
玩家P：×（袭击）

共灰：玩家Q，玩家R，玩家S
```

### 预览窗口
- 可拖动标题栏移动位置
- 可调整窗口大小
- 支持复制、刷新、重置操作
- 部分内容（分隔符等）可编辑

---

## 数据存储

- 数据按房间号隔离存储
- 使用 GM_setValue / GM_getValue 持久化
- 不同房间的数据互不干扰
- 支持清空当前房间数据（设置面板中操作）

---

## 已知问题 / 建议

- 建议在普村使用，职业列表自动从房间配置读取
- 若职业列表读取失败，会使用默认职业列表
- 数据存储在浏览器本地，清除浏览器数据会导致记录丢失
- 菜单模式下滚轮操作被禁用
